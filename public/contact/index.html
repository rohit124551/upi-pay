Reporting Bugs & Requesting Features

For technical bug reports, regex parser edge cases, bank-specific UPI ID format additions, or feature requests, please use our public GitHub repository. Issues submitted with reproducible examples are typically reviewed promptly:

  • GitHub Issues: Submit an Issue on GitHub
  • Discussions & Contributions: Pull requests and feature suggestions from open-source contributors are welcome.

Security & Responsible Disclosure

Because UPI Pay operates with a 100% client-side architecture with zero remote servers or telemetry, sensitive payment data never leaves the client browser. If you discover an edge case or potential client-side vulnerability, please report it directly via email to contact@rohitkumarranjan.in for rapid resolution.

Support Operating Hours

Community support inquiries sent by email or submitted through GitHub issues are monitored regularly during standard Indian Standard Time (IST, UTC+5:30) business hours.
