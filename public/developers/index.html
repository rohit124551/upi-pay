Quickstart Guide

UPI Pay enables developers and AI agents to trigger dynamic UPI payments instantly without creating corporate merchant accounts or paying transaction commissions. You can initiate payments via direct deep links, client-side embeddings, or our command-line tool.

1. Instant URL Integration

Construct a URL following the standard schema to automatically render a payment terminal pre-filled with your recipient, amount, and reference invoice:

https://upi.rohitkumarranjan.in/pay/{upiId}/{amount}/{description}

Example: https://upi.rohitkumarranjan.in/pay/merchant@okaxis/499.00/Invoice-1042

2. Standard NPCI URI Construction

To trigger local payment apps directly on Android or iOS devices, construct standard NPCI UPI URIs:

upi://pay?pa=merchant@okaxis&pn=MerchantName&am=499.00&cu=INR&tn=Invoice1042

API Keys & Client Authentication

Because UPI Pay operates with a 100% client-side zero-server architecture, standard payouts do not require secret backend API keys or monthly API fees. All cryptographic validations and dynamic QR calculations occur in the user's browser or terminal.

Official CLI Tool

The official UPI Pay CLI allows developers and automated AI agents to generate QR codes, parse messy beneficiary lists, and reconcile batches directly from the terminal.

Installation

# Run directly with npx (no install needed)
npx @rohit124551/upi-pay --help

# Or install globally via npm
npm install -g @rohit124551/upi-pay

CLI Commands

# 1. Generate dynamic NPCI QR and UPI intent URI
npx @rohit124551/upi-pay qr --upi merchant@okaxis --amount 499.00 --desc "Invoice 1042"

# 2. Parse unstructured text or WhatsApp messages into payout rows
npx @rohit124551/upi-pay parse --file ./beneficiaries.txt

# 3. Perform 4-way batch reconciliation against a master total
npx @rohit124551/upi-pay reconcile --file ./payouts.csv --total 50000.00

API & URL Scheme Reference

Parameter Type Requirement Description
upiId String Required Valid NPCI Virtual Payment Address (e.g. user@okhdfcbank, vendor@paytm).
amount Decimal Optional Amount in INR with up to 2 decimal places (e.g. 499.00).
desc String Optional URL-encoded transaction note or invoice reference.

Code Implementation Examples

JavaScript / Node.js:

function createUpiPayment(upiId, amount, note) {
  const base = "https://upi.rohitkumarranjan.in/pay";
  return `${base}/${encodeURIComponent(upiId)}/${encodeURIComponent(amount)}/${encodeURIComponent(note)}`;
}

// Example usage
const link = createUpiPayment("merchant@okaxis", 499, "Invoice #1042");
console.log("Payment Link:", link);

Python:

import urllib.parse

def create_upi_link(upi_id: str, amount: float = None, note: str = None) -> str:
    parts = ["https://upi.rohitkumarranjan.in/pay", urllib.parse.quote(upi_id)]
    if amount is not None:
        parts.append(f"{amount:.2f}")
    if note:
        parts.append(urllib.parse.quote(note))
    return "/".join(parts)

print(create_upi_link("merchant@okaxis", 499.0, "Invoice #1042"))
